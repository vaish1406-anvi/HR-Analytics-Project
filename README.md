# HR Analytics Dashboard | SQL + Power BI

## 📌 Project Overview

This project analyzes an HR Analytics dataset using **MySQL** and **Power BI** to identify key workforce trends, employee attrition patterns, salary distribution, and department-wise performance.

The project demonstrates the complete data analysis workflow, including data exploration, data cleaning, SQL-based KPI generation, and interactive dashboard visualization in Power BI.

---

## 🎯 Project Objectives

- Analyze employee attrition trends.
- Identify departments with the highest attrition.
- Compare employee distribution across departments.
- Analyze salary distribution by job role.
- Evaluate overtime, work-life balance, and job satisfaction.
- Build an interactive Power BI dashboard for HR decision-making.

## 💡 Key Insights

- Research & Development has the highest number of employees.
- Employees working overtime have a higher attrition rate.
- Managers receive the highest average monthly salary.
- Sales department records one of the highest attrition rates.
- Employees in lower salary slabs are more likely to leave the organization.
- Work-life balance and job satisfaction significantly impact employee retention.
